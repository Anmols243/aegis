# Regression corpus

Every JSON file here is a scam variant the pipeline **missed** at least once —
generated by the red-team agent (`src/aegis/agents/redteam.py`) or added by hand.

Schema per file:

```json
{
  "id": "rt-2026-10-09-001",
  "variant": "full raw email text...",
  "expected_label": "SCAM",
  "first_missed_at": "2026-10-09T...",
  "mutation_axes": ["rephrased-lure", "fresh-lookalike-domain"],
  "caught_after_fix": false
}
```

`run_regression()` replays the whole corpus through the current pipeline.
A variant that now scores SCAM flips `caught_after_fix` to true — the loop
closing is the story we tell the judges.
